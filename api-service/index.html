QuickTools API

Small, single-purpose JSON endpoints for common developer tasks. No SDK required — plain HTTP.

GET/api/qrcode?text=...&size=300

Returns a PNG QR code. Add &format=base64 to get a JSON data URI instead of a raw image.

curl "https://YOUR-DEPLOYMENT/api/qrcode?text=https://example.com" --output qr.png
GET/POST/api/text-stats?text=...

Word/character/sentence/paragraph counts and estimated reading time.

curl "https://YOUR-DEPLOYMENT/api/text-stats?text=Hello%20world"
→ {"words":2,"characters":11,"charactersNoSpaces":10,"sentences":1,"paragraphs":1,"readingTimeMinutes":1}
GET/api/password?length=16&count=1&symbols=true

Cryptographically random password generation with an entropy/strength estimate. Params: length, count, uppercase, lowercase, numbers, symbols, exclude_ambiguous (all booleans default sensibly).

curl "https://YOUR-DEPLOYMENT/api/password?length=20&symbols=true"
→ {"passwords":["..."],"length":20,"entropyBits":124,"strength":"very strong"}
GET/api/convert-units?category=length&value=5&from=mile&to=kilometer

Length, weight, and temperature conversion. category: length | weight | temperature.

curl "https://YOUR-DEPLOYMENT/api/convert-units?category=temperature&value=100&from=celsius&to=fahrenheit"
→ {"category":"temperature","from":"celsius","to":"fahrenheit","input":100,"result":212}
GET/api/convert-color?value=%234f46e5

Converts a HEX or RGB color to HEX + RGB + HSL.

curl "https://YOUR-DEPLOYMENT/api/convert-color?value=%234f46e5"
→ {"hex":"#4f46e5","rgb":{...},"hsl":{...}}
GET/api/timestamp?value=1735689600

Convert between Unix time (seconds or ms), ISO 8601, and any parseable date string. Omit value for the current time.

curl "https://YOUR-DEPLOYMENT/api/timestamp?value=now"
→ {"unixSeconds":...,"unixMilliseconds":...,"iso":"..."}
GET/api/fake-person?count=5

Synthetic test data for QA/mocking — random names, emails, phone numbers, and addresses. Not real people.

curl "https://YOUR-DEPLOYMENT/api/fake-person?count=2"

Notes

All endpoints support CORS and return JSON (except /api/qrcode's default PNG response). Errors return a 4xx/5xx status with {"error": "..."}.
